| Offset | Field | Evidence |

|02|signed requestedState|Update consumes a request unless it is -1.|
|04|stateWork|020af59c and 020af84c use phases; 020b0da0 uses flags; 020bce70 uses an interpolation-active flag.|

Reset stores the signed-halfword initial state and seeds both history fields
with initialState - 1. The first update resets state work and ticks; the seeded
previous-state value survives that update until a subsequent transition.
Requesting the current state does not restart it. Direct current-state changes
are detected as well as requests. The timer now uses its named unsigned member;
the original pointer-to-integer-to-long-long increment spelling is unnecessary.
The complete 124-byte update still matches exactly.

The 020c937c helper is an absolute tail-call veneer forwarding the object pointer
to 020c3d1c. That function calls the installed deallocator and returns void.
The 020c9388 helper receives an integer initial state, allocates 16 bytes, resets
the record and returns its address. The allocator callback record installed by
020b7138 and selected by dScDSMT::InitResources at 02103290 points to 020ccab4
(Heap::Allocate) and 020cca98 (Heap::_Deallocate). No allocation failure branch
was added: it is absent from the ROM.

Eight callers receive only declaration/argument-representation corrections:
020adbc8, 020aea4c, 020b65e0, 020b9770, 020ca26c, 020b69c4, 020b6a84, 020ca2a8.
The free calls now accept pointers and discard void; the three create callers
pass their original 0, -1, 1 or -2 state values as integers. Their other object
views and interfaces are deliberately outside this slice. All twelve changed
functions compile and strictly link to the same retail bytes.
