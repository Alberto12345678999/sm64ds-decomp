with byte verification. Review covered all 517 enrolled C inputs at this base.

`notes/experiments/ov002-030-language1017.json`.

production enrollment. Explicit C linkage preserves existing exported symbol

reconstruction, not evidence Nintendo used C linkage or these file names.

old reconstruction-tier metrics are not presented as a regenerated audit.
